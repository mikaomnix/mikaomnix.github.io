# فون سيستم (Phone System)

سيستم ويب (PWA) لإدارة محلات الموبايلات والكاش والصيانة — عربي بالكامل، بيشتغل من غير نت، وقابل يتحوّل لتطبيق على جوجل بلاي.

- **اللينك:** https://mikaomnix.github.io/phone/
- **لوحة مدير النظام:** https://mikaomnix.github.io/phone/admin.html

## المكونات
| الملف | الدور |
|---|---|
| `index.html` | الواجهة والتنسيق |
| `core.js` | المحرك المحاسبي (حسابات المحافظ والليمت والعمولات والتصفية والموردين والتقارير) — بيشتغل في المتصفح وفي Node |
| `app.js` | الشاشات + التخزين على الجهاز (IndexedDB) + المزامنة + الحساب والاشتراك + الفروع |
| `tests.js` | اختبارات المحرك (بتشتغل من الإعدادات ← اختبارات النظام) |
| `sw.js` | الشغل من غير نت + استقبال المشاركة من الواتساب (أندرويد) |
| `admin.html` | لوحة مدير النظام (الاشتراكات والخطط والحدود) |
| `drop.html` | لينك رفع اسكرينات للمورد من غير حساب |
| `db/50-phone.sql` | قاعدة البيانات على Supabase (جداول `ph_*` + RLS) |

## طريقة الشغل
- كل حركة بتتسجل كحدث ثابت مايتمسحش، وده بيدّي **سجل تدقيق كامل** (مين، إمتى، الجهاز، الفرع).
- التصحيح بيتم بحركة عكسية، مش بمسح.
- البيانات بتتحفظ على الجهاز الأول، وبتترفع للسيرفر أول ما النت يرجع **من غير تكرار**.
- السيرفر نفسه بيتأكد من **الصلاحية والفرع والاشتراك** قبل ما يقبل أي حركة.

## التشغيل محلياً
```bash
node phone/serve.js
```
وبعدين افتح http://localhost:5181

## النشر
ارفع ملفات فولدر `phone` على مستودع `mikaomnix/mikaomnix.github.io` في فولدر `phone/`. GitHub Pages بينشرها خلال دقيقة.

## قاعدة البيانات
- شغّل `db/50-phone.sql` مرة واحدة في SQL Editor بتاع Supabase (المشروع `rzvncstjattlklpdtkfn`).
- آمن يتشغّل أكتر من مرة.
- الفرونت فيه **المفتاح العام (publishable) بس**.
- أي مفتاح سري (زي مفتاح Gemini للتحليل الذكي للصور) بيتحط في **Supabase ← Edge Functions ← Secrets**، وعمره ما بيتكتب في الكود.

## النسخ الاحتياطي
- **من جوه السيستم:** الإعدادات ← النسخ الاحتياطي ← «تنزيل نسخة مشفّرة» (بكلمة سر، والصور اختياري).
- **الاستعادة:** بتفحص النسخة وتوريك الأرقام قبل ما تطبّقها.
- **السيرفر:** Supabase بياخد نسخ يومية تلقائي في الخطط المدفوعة.

## محاذير مهمة
- **قراية SMS تلقائي:** المتصفح مش بيقرا الرسايل، وجوجل بلاي بيرفض صلاحية `READ_SMS` لأغلب التطبيقات. البدائل اللي في السيستم:
  - لصق الرسالة.
  - المشاركة من الواتساب (Share Target).
  - ربط SMS بتطبيق أتمتة (MacroDroid على أندرويد، أو الاختصارات على آيفون) بمفتاح خاص بكل مصدر.
  - نسخة أندرويد الأصلية ممكن تستخدم Notification Listener (المرحلة ح).
- **فحص IMEI:** مفيش خدمة رسمية مفتوحة في مصر لحالة الـ IMEI. السيستم بيعمل فحص صحة الرقم + قايمة سودا داخلية.
- **الإيميل التلقائي لتقرير اليوم:** محتاج خدمة إرسال (زي Resend) بمفتاح المالك يضيفه. لحد وقتها التقرير بيتبعت واتساب وصفحة وPDF.
