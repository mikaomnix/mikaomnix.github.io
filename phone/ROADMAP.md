# خريطة طريق فون سيستم

## المراحل
- [x] **أ — الأساس:**
  - دخول/تسجيل/نسيت كلمة السر، محل + فروع، ٦ أدوار + ١٧ صلاحية تفصيلية (بيتحقق منها السيرفر).
  - اختيار الفرع وعرض كل الفروع للمالك، المظهر الكامل (ثيمات، ألوان، خط، أيقونات، خلفية بوضوح، لوجو، داكن)، اختصارات الكيبورد، سجل التدقيق، النسخ الاحتياطي.
  - موروث من محرك كاشينو: المحافظ والليمت اليومي والشهري، صندوق التصفية (صور جماعي، SMS، واتساب، لينك المورد) مع منع التكرار، الموردين، إنستاباي، تقفيل اليوم بخطوات، تقرير آخر اليوم.
- [ ] **ب — الكاش:** ليمت إيداع/إرسال منفصل عن الاستقبال، تحذير ٨٠٪ و٩٥٪، شرائح عمولة وسعر جملة للوكلاء، سقف مديونية لعملاء الجملة، مقارنة أسعار موردين الكاش، سجل الشرايح.
- [ ] **ج — اليومية والتحذيرات:** يومية سريعة (فلان ساب/أخد فلوس، سلفة، سحب/إيداع درج)، عد الدرج في الفتح، شاشة كشف الشبهات.
- [ ] **د — المخزون والمبيعات:** أصناف بمتغيرات، IMEI/سيريال، باركود (كاميرا وقارئ)، جرد، تحويل بين الفروع، فواتير بيع/شراء/مرتجع/عرض سعر/تقسيط، فاتورة 80mm وA4، شاشة كاشير سريعة.
- [ ] **هـ — الصيانة والمستعمل:** تذكرة صيانة بباركود وكلمة سر مشفرة، موردين القطع وأرخص سعر، تقييم المستعمل بالصور والذكاء الاصطناعي، القايمة السودا للـ IMEI، إقرار بيع بتوقيع.
- [ ] **و — العمال والتقارير:** حضور بكارت باركود، ورديات وتنقل بين الفروع، مرتبات وسلف وعمولات، التقارير والتحليلات، المساعد الذكي.
- [ ] **ز — الاشتراكات:** خطط وحدود فروع ومستخدمين وفواتير — **الأساس اتعمل في (أ)** (لوحة الأدمن فيها الخطط والحدود والمدفوع)، ناقص تنبيه قبل الانتهاء وفاتورة اشتراك للعميل.
- [ ] **ح — جوجل بلاي:** TWA + Capacitor لـ Notification Listener.

## أقوى ١٥ ميزة (من Square / Lightspeed / Shopify POS / Odoo / RepairShopr / Zoho)
1. ✅ بحث شامل سريع (F1 / Ctrl+K) — هيتوسّع للـ IMEI والباركود في (د)
2. ✅ اختصارات الكيبورد للكاشير (F1–F8)
3. ⏳ شاشة كاشير سريعة للموبايل (د)
4. ✅ كشف حساب العميل بواتساب (موروث)
5. ⏳ هامش الربح اللحظي وانت بتبيع (د)
6. ⏳ مساعد ذكي بالعربي عن بيانات المحل (و)
7. ⏳ إشعارات Push (ج)
8. ⏳ صفحة متابعة الصيانة للعميل برابط (هـ)
9. ⏳ نقاط ولاء للعملاء (د)
10. ⏳ حجز منتج بعربون (د)
11. ⏳ إعادة طلب تلقائي عند الحد الأدنى (د)
12. ⏳ توقيع العميل على الشاشة (هـ)
13. ⏳ أهداف مبيعات لكل عامل (و)
14. ⏳ مقارنة الفروع جنب بعض (و)
15. ⏳ تسليم وردية بعد الدرج (ج)
